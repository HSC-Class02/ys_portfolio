# Park Youngseo | Portfolio Dashboard

개인 포트폴리오 웹사이트입니다. 한국어와 영어를 함께 사용하며, 파스텔 블루 메인 화면과 카테고리별 상세 페이지로 구성했습니다.

## Portfolio structure

| Category | Contents |
|---|---|
| Home | 포트폴리오 요약, 주요 관심 분야, 대표 프로젝트 바로가기 |
| About | 자기소개, 관심 분야, 기술 역량 |
| AI-Generated Reports | AI 기반 기업 분석 자동화 및 보고서 프로젝트 |
| Financial Dashboard | 씨어스(씨어스테크놀로지) DART 재무제표 수집·분석 대시보드 |
| Research & Activities | 간호윤리·헬스케어 AI 탐구, 수어 동아리, 교내 행사, 노인요양원 봉사 |
| Certificates | AI 윤리 관련 MOOC 수료 및 인증 자료 |

## Project navigation

- **About**: 학업 및 관심 분야, 개인 프로필
- **AI-Generated Reports**: 기업 데이터 기반 자동 분석 결과물
- **Financial Dashboard**: DART 공시 데이터와 재무비율 분석 프로젝트
- **Research & Activities**: 전공 탐구와 교내외 활동
- **Certificates**: 수료증 및 인증 링크

## Tech stack

- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

현재 웹사이트는 index.html 한 파일에 스타일과 동작을 포함한 단일 페이지 구조입니다. 별도 빌드 도구나 패키지 설치 없이 브라우저에서 실행할 수 있습니다.

## Run locally

1. 저장소를 내려받습니다.
2. index.html을 브라우저에서 엽니다.

## GitHub Pages deployment

GitHub 저장소의 Settings → Pages에서 배포 소스를 설정합니다.

- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

저장 후 다음 주소에서 확인할 수 있습니다.
